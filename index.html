Figure
Loop sweeps around the start in one steady circuit. Crisscross visits the same via-points in a scrambled order instead — cutting back and forth through the middle rather than tracing a clean perimeter, so it turns up more small/unexpected roads. Figure traces a chosen shape — it'll only ever roughly resemble it, since the route still has to follow real roads. Draw (experimental): sketch any closed shape yourself and it's traced the same way.

Detailed
Detailed anchors the route on real trail data from several sources and tries several shapes before settling — best off-road quality, a bit slower. Fast takes the first result instead — noticeably quicker, at the cost of distance/N-road refinement. Only applies to Road — Gravel/MTB always run full quality, since finding genuinely good tracks is the whole point there.
Drag Route: grab the line anywhere and drag it — release to snap onto the nearest real, rideable road and re-route just that section. Select Segment (experimental): tap a start point then an end point — that stretch is immediately cleared and locked in, and you can drag anywhere inside it right away, no other toggle needed. Drags inside a selected segment prefer unpaved ground; the rest of the route stays protected.
Trims any out-and-back stretches from the route you're currently looking at — a pure geometry cleanup, no re-routing, so the rest of the route can't shift or change.
Ride some nice gravel? Upload the GPX and mark it a favourite — nothing about your actual route is stored, only which rough patches of ground (~60m) got favourited by how many different riders. That nudges future routes toward ground real people enjoyed.
